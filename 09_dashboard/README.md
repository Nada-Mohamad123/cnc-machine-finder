# Dashboard - CNC Machine Finder (Streamlit)

Install once:   pip install -r 09_dashboard/requirements.txt
Run:            streamlit run 09_dashboard/app.py      (from the project root, or any folder)

Reads 07_data_outputs/machines_final.csv. Keep the folder structure unchanged.

Tabs: Machine Finder (budget + size shortlist) | Market overview | Price vs size | Data quality.
Prices are mostly website estimates, and the dashboard says so on every page.
